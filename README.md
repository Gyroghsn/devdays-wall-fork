# 🎉 GitHub Dev Days: Wall of Fame

Welcome to the **Master your projects with Git & GitHub** workshop!

This repository powers a website where **every participant gets a card**, and each card arrives through
a real pull request. By the end of the workshop you'll have:

- ✅ your card on a public website: **https://hadeelhs.github.io/devdays-wall/**
- ✅ a merged contribution to a real project
- ✅ green squares on your GitHub profile

## 👉 Start here: [MISSIONS.md](MISSIONS.md)

## What's inside

| Path | What it is |
|---|---|
| `participants/` | One card per participant: `<username>.json` |
| `quiz/answers.md` | The 💥 boss level (merge conflicts!) |
| `index.html`, `assets/` | The Wall of Fame website |
| `.github/workflows/` | The 🤖 Welcome Bot that checks and merges pull requests, and the website deployment |
